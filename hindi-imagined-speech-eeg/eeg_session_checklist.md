## 1. Before the participant arrives

- [ ] Recording room prepared and quiet.
- [ ] Computer/display tested.
- [ ] Stimulus-presentation software tested.
- [ ] EEG device charged/powered and available.
- [ ] Actual EEG device and configuration recorded.
- [ ] Required electrodes/sensors checked.
- [ ] Event-marker system tested.
- [ ] Data storage location available and access controlled.
- [ ] Participant documents ready.
- [ ] Participant Information Sheet ready.
- [ ] Informed Consent Form ready.
- [ ] Screening Form ready.
- [ ] Participant Instructions ready.
- [ ] Session folder created using coded participant/session ID.

## 2. Participant arrival and consent

- [ ] Confirm participant study ID.
- [ ] Provide/explain Participant Information Sheet.
- [ ] Allow participant to ask questions.
- [ ] Confirm eligibility screening is complete.
- [ ] Obtain written informed consent before EEG recording.
- [ ] Give participant a copy of the signed consent form.
- [ ] Store the research copy of consent securely and separately from EEG data.

## 3. Pre-recording screening and setup

- [ ] Confirm participant is comfortable proceeding.
- [ ] Confirm Hindi task instructions are understood.
- [ ] Confirm vision is adequate for the task.
- [ ] Confirm no new relevant information affects eligibility.
- [ ] Fit EEG equipment according to the actual device protocol.
- [ ] Record device name/model.
- [ ] Record channel count.
- [ ] Record sampling rate.
- [ ] Record reference/ground configuration where applicable.
- [ ] Check signal quality/channel impedance or equivalent device-specific QC.
- [ ] Adjust equipment if needed for comfort.
- [ ] If eye tracker is retained, complete calibration and document result.

## 4. Stimulus/event verification

Before the first participant session, and according to the approved stimulus system:

- [ ] Verify fixation duration = **500 ms**.
- [ ] Verify Hindi word display duration = **300 ms**.
- [ ] Verify imagined-speech window = **3,000 ms**.
- [ ] Verify rest/reset = **1,000 ms**.
- [ ] Verify the 6 approved Hindi word classes/stimuli are loaded.
- [ ] Verify randomization procedure.
- [ ] Verify trial/block numbering.
- [ ] Verify event markers are generated in the correct order.
- [ ] Verify marker-to-EEG synchronization/latency using the validated setup.

### Expected conceptual markers

| Marker | Meaning |
|---|---|
| `REST_ON` | Rest/reset begins |
| `CUE_ON` | Hindi word appears |
| `IMAGINE_ON` | Imagined-speech window begins |
| `IMAGINE_OFF` | Imagined-speech window ends |
| `TRIAL_END` | Trial complete |

## 5. Participant instruction check

Before recording:

- [ ] Explain that the participant will silently imagine saying each displayed Hindi word.
- [ ] Explain that they must not speak aloud.
- [ ] Explain that they should not whisper or lip-sync.
- [ ] Explain that they should avoid intentional lip/tongue movement.
- [ ] Explain the fixation, word, imagination, and rest sequence.
- [ ] Explain that they may ask for a break or stop at any time.
- [ ] Confirm participant can repeat the task instructions in their own words.

## 6. Practice block

Current protocol: **55 trials (~4 minutes)**.

- [ ] Start practice recording.
- [ ] Confirm event markers are being recorded.
- [ ] Observe participant understanding and comfort.
- [ ] Check signal quality.
- [ ] Stop/restart only according to documented procedure if a technical problem occurs.
- [ ] Record any deviation or issue.

## 8. Breaks and participant comfort

Between blocks:

- [ ] Provide scheduled rest break.
- [ ] Ask participant whether they are comfortable continuing.
- [ ] Check headset fit if needed.
- [ ] Allow additional pause if needed.
- [ ] Document any unusual discomfort or protocol deviation.

## 9. End of session

- [ ] Stop EEG recording.
- [ ] Save raw EEG using coded participant/session ID.
- [ ] Save event/marker file.
- [ ] Verify files open/read correctly.
- [ ] Confirm expected trial/block counts.
- [ ] Remove EEG equipment carefully.
- [ ] Ask participant about discomfort or concerns.
- [ ] Complete any approved post-session questionnaire/debrief.
- [ ] Remind participant about withdrawal/contact procedure if appropriate.

## 10. Data handling immediately after session

- [ ] Copy/transfer data only to approved secure institutional storage.
- [ ] Confirm raw data are not stored with direct participant identifiers.
- [ ] Keep consent/identifying documents separate from EEG research data.
- [ ] Verify backup according to institutional procedure.
- [ ] Record session completion status.
- [ ] Record technical problems and deviations.
- [ ] Record any missing/corrupted files.
- [ ] Do not upload raw identifiable participant data to GitHub.
